# Quantum State Tomography and Bell Test
This repository contains MATLAB scripts developed for the analysis of experiments in quantum state tomography and Bell inequality measurements using a pulsed laser optical setup. 
The tomography script processes raw video data recorded from four detectors, extracts the measured intensities over time, identifies pulse events using a dynamic threshold, and performs coincidence analysis within a selected time window. Using these measurements, the script reconstructs the density matrix of the measured state and visualizes it in three dimensions. \\
The Bell analysis script processes 16 independent measurement projections in order to calculate the correlation coefficients ((E)) and the CHSH Bell parameter ((S)).
